드라이브 설정 데이터

🚀 hello.c 커널 모듈 코드에 DTB(DTB Overlay)에서 특정 값을 읽어와 출력하는 기능을 추가한 코드입니다. 커널 모듈을 빌드하고 테스트하면 DTB 값을 읽어오는지 확인할 수 있습니다.

1. 주요 기능:

1) Device Tree에서 my-custom-property 값 읽기
2) Device Tree에서 my_led 노드의 속성 값 출력
3) 모듈이 insmod될 때 DTB 값을 읽고 출력
4) 모듈이 rmmod될 때 "Goodbye" 메시지 출력

📌 2. 코드 (hello.c)

#include <linux/init.h>
#include <linux/module.h>
#include <linux/kernel.h>
#include <linux/of.h>
#include <linux/of_device.h>

// 모듈 정보
MODULE_LICENSE("GPL");
MODULE_AUTHOR("Your Name");
MODULE_DESCRIPTION("A simple Hello World Kernel Module with DTB Read");
MODULE_VERSION("1.0");

// DTB에서 값을 읽어 출력하는 함수
static void read_dtb_values(void) {
    struct device_node *led_node;
    const char *label;
    u32 reg, active_state;

    printk(KERN_INFO "Searching for 'my_led@7' in DTB...\n");

    // 1️⃣ 경로 기반 검색
    led_node = of_find_node_by_path("/my_led@7");
    if (led_node) {
        printk(KERN_INFO "Found DTB node 'my_led@7' via path!\n");
    } else {
        printk(KERN_ERR "Failed to find 'my_led@7' via path. Trying name-based search...\n");

        // 2️⃣ 이름 기반 전체 검색
        led_node = of_find_node_by_name(NULL, "my_led@7");
        if (!led_node) {
            printk(KERN_ERR "Failed to find 'my_led@7' via name-based search.\n");

            // 3️⃣ name 속성 확인을 위한 검색
            led_node = of_find_node_by_name(NULL, "my_led");
            if (!led_node) {
                printk(KERN_ERR "Failed to find 'my_led' via name-based search.\n");
                return;
            }
        }
    }

    printk(KERN_INFO "Found 'my_led@7' DTB node!\n");

    // `label` 속성 읽기
    if (of_property_read_string(led_node, "label", &label) == 0) {
        printk(KERN_INFO "LED Label: %s\n", label);
    } else {
        printk(KERN_ERR "Failed to read 'label' property\n");
    }

    // `reg` 속성 읽기
    if (of_property_read_u32(led_node, "reg", &reg) == 0) {
        printk(KERN_INFO "LED Register: %u\n", reg);
    } else {
        printk(KERN_ERR "Failed to read 'reg' property\n");
    }

    // `active_state` 속성 읽기
    if (of_property_read_u32(led_node, "active_state", &active_state) == 0) {
        printk(KERN_INFO "LED Active State: %u\n", active_state);
    } else {
        printk(KERN_ERR "Failed to read 'active_state' property\n");
    }
}

// 모듈 초기화 함수
static int __init hello_init(void) {
    printk(KERN_INFO "Hello, Kernel World!\n");
    read_dtb_values();  // DTB에서 값 읽고 출력
    return 0; // 성공적으로 로드됨
}

// 모듈 종료 함수
static void __exit hello_exit(void) {
    printk(KERN_INFO "Goodbye, Kernel World!\n");
}

// 초기화 및 종료 함수 등록
module_init(hello_init);
module_exit(hello_exit);

3. 내용 설명

1) DTB에서 값 읽기 (read_dtb_values())

  • 루트 노드에서 "my-custom-property" 값을 가져옴.
  • "my_led@7" 노드를 찾아 "label", "reg", "active_state" 값을 가져옴.
  • 성공하면 printk()를 통해 커널 로그에 출력.

2) 커널 모듈 등록

  • hello_init()에서 DTB 값을 읽고 출력.
  • hello_exit()에서 종료 메시지 출력.

4. 빌드 및 사용 방법

1️⃣ Makefile 작성

obj-m += hello.o

all:
    make -C /lib/modules/$(shell uname -r)/build M=$(PWD) modules

clean:
    make -C /lib/modules/$(shell uname -r)/build M=$(PWD) clean

2️⃣ 컴파일

make

3️⃣ 모듈 로드 (insmod)

sudo insmod hello.ko
🔹 dmesg 로그 확인: 
sudo dmesg | tail -n 10

4️⃣ 모듈 제거 (rmmod)

sudo rmmod hello

6. 정리

✔ DTB Overlay에서 my-custom-property 및 my_led@7 노드의 속성을 읽어 출력하는 기능 추가
✔ 커널 모듈이 로드될 때 (insmod) DTB 값을 읽어 출력
✔ 커널 모듈이 제거될 때 (rmmod) 종료 메시지 출력
