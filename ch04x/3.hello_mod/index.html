hello 모듈

리눅스 드라이버를 작성하려면 Linux 커널 모듈을 작성해야 합니다. 간단한 hello 모듈을 예제로 만들어 보겠습니다. 이 모듈은 커널 로그에 메시지를 출력하고, 로드 및 언로드 시점을 표시합니다.

리눅스 드라이버를 작성하려면 Linux 커널 모듈을 작성해야 합니다. 간단한 hello 모듈을 예제로 만들어 보겠습니다. 이 모듈은 **커널 로그**에 메시지를 출력하고, 로드 및 언로드 시점을 표시합니다.

1. hello.c 파일 작성

아래 코드는 간단한 Linux 커널 모듈입니다.

#include <linux/init.h>    // init and exit macros
#include <linux/module.h>  // module macros
#include <linux/kernel.h>  // printk

// 모듈 정보
MODULE_LICENSE("GPL");
MODULE_AUTHOR("Your Name");
MODULE_DESCRIPTION("A simple Hello World Kernel Module");
MODULE_VERSION("1.0");

// 모듈 초기화 함수
static int __init hello_init(void) {
    printk(KERN_INFO "Hello, Kernel World!\n");
    return 0; // 성공적으로 로드되었음을 의미
}

// 모듈 종료 함수
static void __exit hello_exit(void) {
    printk(KERN_INFO "Goodbye, Kernel World!\n");
}

// 초기화 및 종료 함수 등록
module_init(hello_init);
module_exit(hello_exit);

2. Makefile 작성

커널 모듈을 빌드하려면 Makefile이 필요합니다. 다음은 해당 모듈에 대한 간단한 Makefile 예제입니다.

obj-m += hello.o

all:
    make -C /lib/modules/$(shell uname -r)/build M=$(PWD) modules

clean:
    make -C /lib/modules/$(shell uname -r)/build M=$(PWD) clean

3. 컴파일

1) 파일 구조: 

hello_module/
├── Makefile
└── hello.c

2) 터미널에서 다음 명령어를 실행합니다:

make 명령어를 수행하여 커널 모듈 생성

6. gcc 를 이용한 컴파일

gcc를 사용하여 Linux 커널 모듈을 컴파일하려면 커널 빌드 시스템을 거쳐야 하기 때문에 일반적으로 단순히 gcc로 직접 컴파일하지는 않습니다. 하지만 커널 빌드 시스템을 사용하지 않고 gcc로 컴파일할 수 있는 방법을 소개합니다.

1) 커널 헤더 설치 확인 gcc로 컴파일하려면 커널 헤더 파일이 필요합니다. 아래 명령으로 설치 여부를 확인하거나 설치합니다.

sudo apt update
sudo apt install -y linux-headers-$(uname -r)

2) hello.c 코드 작성

Jetson Orin Nano의 작업 디렉토리에서 hello.c 파일을 작성합니다:

nano hello.c

주어진 코드를 복사하여 붙여넣고 저장합니다.

3) 커널 모듈 컴파일

커널 모듈 컴파일 시 필요한 플래그를 포함하여 gcc로 컴파일합니다.

gcc -Wall -Wextra -c -o hello.o hello.c -I/lib/modules/$(uname -r)/build/include

설명:

  • -Wall -Wextra: 모든 경고 메시지를 활성화합니다.
  • -c: 개체 파일만 생성합니다.
  • -o hello.o: 출력 파일 이름을 지정합니다.
  • -I: 커널 헤더 파일 경로를 지정합니다.

4) 링킹하여 .ko 파일 생성

ld -r -o hello.ko hello.o

7. 테스트 환경

  • Linux 커널 헤더가 설치되어 있어야 합니다. 다음 명령으로 확인 및 설치: 

    sudo apt update
sudo apt install linux-headers-$(uname -r)

  • 테스트는 root 권한으로 수행해야 합니다(sudo 사용).

8. 추가 참고

  • printk() : 함수는 로그 레벨을 지정합니다:
  • KERN_INFO: 정보 메시지.
  • KERN_WARNING: 경고 메시지.
  • KERN_ERR: 에러 메시지.

로그 레벨에 따라 메시지가 dmesg나 로그 파일에 표시됩니다. 실습 후 생성된 .ko 파일은 필요하지 않으면 제거하세요.
