부팅과정

리눅스 부팅 과정에 대해서 살펴본다.

1. Jetson Orin Nano 초기 부팅 과정

  1. BootROM 단계
    Jetson Orin Nano의 부팅 과정은 BootROM에서 시작된다. BootROM은 부트 디바이스(eMMC, SD 카드, USB 등)를 검색하고 부트로더를 로드한다.

  2. cboot (NVIDIA의 초기 부트로더) 실행
    BootROM이 부트 디바이스에서 cboot(Chain Bootloader)를 실행한다. cboot는 기본적으로 extlinux.conf 파일을 분석하고 해당 설정에 따라 커널을 로드한다.

  3. 커널 및 DTB 로드
    extlinux.conf에 지정된 커널(/boot/Image)과 장치 트리(/boot/dtb/kernel_tegra234-p3767-0003-p3768-0000-a0.dtb)를 메모리에 로드한다.

  4. Initrd (초기 램디스크) 로드
    INITRD /boot/initrd가 지정되어 있다면, 초기 램디스크를 로드하여 루트 파일 시스템을 마운트하기 전에 필요한 초기화 작업을 수행한다.

  5. 커널 실행 및 루트 파일 시스템 마운트
    커널이 실행되면서 APPEND에서 지정된 커널 인자를 기반으로 루트 파일 시스템을 마운트하고, 사용자 공간 프로세스를 실행하여 운영 체제가 완전히 부팅된다.

2. 커널부팅컴멘드

1) cboot 참조 디렉토리:

/boot/extlinux
jetson@ubuntu:/boot/extlinux$ ls
extlinux.conf  extlinux.conf.nv-update-extlinux-backup
jetson@ubuntu:/boot/extlinux$,

2) extlinux.conf 파일: 

TIMEOUT 30
DEFAULT primary

MENU TITLE L4T boot options

LABEL primary
      MENU LABEL primary kernel
      LINUX /boot/Image
      FDT /boot/dtb/kernel_tegra234-p3767-0003-p3768-0000-a0.dtb
      INITRD /boot/initrd
      APPEND ${cbootargs} root=PARTUUID=e23f85c5-258e-4a6a-8caa-45460dbe2b5c rw rootwait rootfstype=ext4 mminit_loglevel=4 console=ttyTCU0,115200 console=ttyAMA0,115200 firmware_class.path=/etc/firmware fbcon=map:0 net.ifnames=0 nospectre_bhb nv-auto-config

# When testing a custom kernel, it is recommended that you create a backup of
# the original kernel and add a new entry to this file so that the device can
# fallback to the original kernel. To do this:
#
# 1, Make a backup of the original kernel
#      sudo cp /boot/Image /boot/Image.backup
#
# 2, Copy your custom kernel into /boot/Image
#
# 3, Uncomment below menu setting lines for the original kernel
#
# 4, Reboot

# LABEL backup
#    MENU LABEL backup kernel
#    LINUX /boot/Image.backup
#    FDT /boot/dtb/kernel_tegra234-p3767-0003-p3768-0000-a0.dtb
#    INITRD /boot/initrd
#    APPEND ${cbootargs}

3. extlinux.conf 파일 설명

Jetson Orin Nano 보드의 extlinux.conf 파일은 부트로더가 부팅할 커널, 장치 트리, 초기 램디스크 및 커널 부팅 인자를 정의하는 설정 파일이다. 이 파일을 통해 시스템이 부팅될 때 사용할 커널 및 기타 설정을 구성할 수 있다.

이 파일은 extlinux 부트로더에서 사용되며, 기본적으로 다음과 같은 항목을 포함한다:

  • TIMEOUT 30: 부트 메뉴에서 선택을 기다리는 시간(초 단위)
  • DEFAULT primary: 기본으로 부팅할 항목 지정
  • MENU TITLE L4T boot options: 부트 메뉴의 제목
  • LABEL primary: "primary"라는 레이블을 가진 기본 부팅 항목
    • MENU LABEL primary kernel: 부팅 메뉴에서 표시될 이름
    • LINUX /boot/Image: 커널 이미지 파일의 경로
    • FDT /boot/dtb/kernel_tegra234-p3767-0003-p3768-0000-a0.dtb: 장치 트리 블롭(Device Tree Blob, DTB)의 경로
    • INITRD /boot/initrd: 초기 램디스크(initrd)의 경로
    • APPEND: 커널 부팅 인자를 설정하는 부분으로, 루트 파일 시스템, 콘솔 설정, 네트워크 인터페이스 및 기타 설정을 포함

4. 커스텀 커널 사용 시 주의할 점

  • 기존 커널을 백업한 후 새로운 커널을 /boot/Image에 복사
  • extlinux.conf에서 기존 커널을 백업 부팅 옵션으로 추가하여 문제가 발생하면 원래 커널로 부팅할 수 있도록 설정
  • APPEND 부분을 적절히 수정하여 커널이 정상적으로 실행될 수 있도록 조정
