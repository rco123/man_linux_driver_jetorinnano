1. 보드의 구별자 확인

1) compatible 속성값 확인

속성값은 커널이 오브레이 적용시, 적용하는 것은 판단하는 기준이 된다.

명령어: 

cat /sys/firmware/devicetree/base/compatible

실행결과: 

cat /sys/firmware/devicetree/base/compatible

jetson@ubuntu:/sys/class/gpio$ cat /sys/firmware/devicetree/base/compatible

jetson@ubuntu:/sys/class/gpio$

2. Overlay 를 이용하는 방법

overlay dtsi 파일을 작성하여 시스템에 적용할 수 있도록 한다.

1) 기본형: 

/dts-v1/;
/plugin/;

/ {
    overlay-name = "My Jetson Overlay";
    jetson-header-name = "Jetson 40pin Header";
    compatible = "nvidia,p3768-0000+p3767-0003";  

    fragment@0 {
        target-path = "/";
        __overlay__ {
            my-custom-property = "This Is My Overlay";



        };
    };
};

2) 추가할 내용 :

 my_led@7 {
    compatible = "my_led_run";  /* 호환되는 장치 유형 */
    label = "my_led";           /* LED 이름 */
    reg = <492>
    pin = "7";                 /* GPIO 핀 번호 */
    active_state = <0>;         /* 활성화 상태 */
    default_state = "off";      /* 기본 상태 */
};

3) 최종 파일 작성

/* 파일이름 : my-overlay.dts */

/dts-v1/;
/plugin/;

/ {
    overlay-name = "My Jetson Overlay";
    jetson-header-name = "Jetson 40pin Header";
    compatible = "nvidia,p3768-0000+p3767-0003";  

    fragment@0 {
        target-path = "/";
        __overlay__ {
            my-custom-property = "This Is My Overlay";

            my_led@7 {
                compatible = "my_led_run";  /* 호환되는 장치 유형 */
                label = "my_led";           /* LED 이름 */
                reg = <492>;
                pin = "7";                 /* GPIO 핀 번호 */
                active_state = <0>;         /* 활성화 상태 */
                default_state = "off";      /* 기본 상태 */
            };
        };
    };
};

3. dts 컴파일

다음 명령어를 입력하여 DTS 소스 파일을 오버레이 파일로 컴파일하세요:

$ dtc -O dtb -o my-overlay.dtbo -@ my-overlay.dts

4. overlay 적용

새로운 오버레이 파일을 /boot/ 디렉터리에 복사한 후, Jetson‑IO가 해당 오버레이 파일을 찾아 이를 적용할 수 있도록 합니다:

1) dtbo 파일 복사 

$ sudo cp my-overlay.dtbo /boot

2) dtbo 적용

jetson-io 라이브리에서 제공하는 툴을 이용하여, dtbo 를 적용한다.

명령문: 

$ sudo /opt/nvidia/jetson-io/config-by-hardware.py -l

출력 결과:

3) overlay 적용하기

다음 명령을 수행하여 overlay 가 적용되도록 한다.

$ sudo /opt/nvidia/jetson-io/config-by-hardware.py -n "My Jetson Overlay"

jetson@ubuntu:~$ sudo /opt/nvidia/jetson-io/config-by-hardware.py -n "My Jetson Overlay"
Configuration saved to /boot/kernel_tegra234-p3767-0003-p3768-0000-a0-user-custom.dtb.
Reboot system to reconfigure.

보드를 리부팅하여, 적용된 결과를 확인한다.

1) 데이터 확인

Jetson 보드에서 최종 디렉토리에 있는 값들을 확인하는 명령어들을 나열하면 다음과 같습니다.

  • 확인 명령문:
cat /proc/device-tree/my_led@7/compatible | xargs --null echo
cat /proc/device-tree/my_led@7/default_state | xargs --null echo
cat /proc/device-tree/my_led@7/label | xargs --null echo
cat /proc/device-tree/my_led@7/name | xargs --null echo
cat /proc/device-tree/my_led@7/pin | xargs --null echo

xxd /proc/device-tree/my_led@7/reg | xargs --null echo
xxd /proc/device-tree/my_led@7/active_state | xargs --null echo

printf "%d\n" $(( 0x$(xxd -p /proc/device-tree/my_led@7/reg) ))
printf "%d\n" $(( 0x$(xxd -p /proc/device-tree/my_led@7/active_state) ))
