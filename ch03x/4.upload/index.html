보드 이미지 전송

Jetson Orin Nano 보드에 NVIDIA SDK를 이용하여 JetPack을 설치하고 업로드하는 방법을 단계별로 설명해 드리겠습니다.

1. Jetson SDK Manager 다운로드 및 설치

✅ 개발 PC에 Ubuntu 18.04 / 20.04 / 22.04 설치

  • Jetson SDK Manager는 Ubuntu 기반에서 실행되므로 개발 PC에 Ubuntu가 설치되어 있어야 합니다.
  • Windows 또는 Mac을 사용 중이라면 **가상머신(VM) 또는 WSL2가 아닌 실제 Ubuntu 시스템을 사용**해야 합니다.

✅ Jetson SDK Manager 다운로드

  1. NVIDIA 공식 다운로드 페이지에서 최신 버전의 Jetson SDK Manager를 다운로드합니다.
  2. 다운로드한 .deb 파일을 설치합니다.
sudo dpkg -i sdkmanager_<version>.deb
sudo apt-get update
sudo apt-get install -f
  1. 설치 후 실행: 
    sdkmanager

2. Jetson Orin Nano를 Recovery Mode로 설정

  1. Jetson Orin Nano 보드를 USB-C 케이블로 Ubuntu PC와 연결합니다.
  2. 전원을 끄고(AC 어댑터 제거) **RECOVERY 버튼**을 누른 상태에서 **전원 버튼을 눌러 부팅**합니다.
  3. lsusb 명령어를 실행하여 NVIDIA 장치가 인식되었는지 확인합니다.

lsusb | grep NV
정상적으로 연결되면 "NVIDIA Corp." 라는 디바이스가 표시됩니다.

3. JetPack 설치 (Ubuntu PC에서 Jetson SDK Manager 실행)

1) **Jetson SDK Manager를 실행**합니다. 

sdkmanager

2) 로그인 후 JetPack 선택

  • NVIDIA 개발자 계정으로 로그인합니다.
  • "Target Hardware"에서 Jetson Orin Nano 선택
  • "JetPack Version"에서 JetPack 5.x 이상 선택

3) 설치 구성 선택

  • "Host Components": 개발 PC에 필요한 CUDA, TensorRT 등 선택
  • "Target Components": Jetson Orin Nano에 설치할 JetPack 구성 선택 (기본 옵션 사용)

4) Flash 진행

  • "Flash OS"를 선택하면 Jetson Orin Nano에 Ubuntu 기반의 JetPack OS가 설치됩니다.
  • 설치 중 "USB 연결을 확인하세요" 메시지가 나오면 USB-C 케이블이 잘 연결되어 있는지 확인하세요.

4. Jetson Orin Nano 설정 및 추가 패키지 설치

✅ Jetson 첫 부팅

  1. 설치가 완료되면 Jetson Orin Nano를 재부팅합니다.
  2. **초기 설정 (Ubuntu 사용자 계정, Wi-Fi, 키보드 등)**을 완료합니다.

✅ 개발 환경 구성

설치 후 Jetson에서 다음을 실행하여 개발 환경을 확인할 수 있습니다.

# CUDA 버전 확인
nvcc --version

# TensorRT 버전 확인
dpkg -l | grep nvidia-tensorrt

# GPU 상태 확인
tegrastats

필요한 추가 패키지를 설치하려면 다음 명령어를 사용하세요.

sudo apt update && sudo apt upgrade
sudo apt install python3-pip python3-numpy python3-opencv
