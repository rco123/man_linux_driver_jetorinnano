커널 이미지 복사

1. 생성된 이미지 복사

1) 생성된 커널 이미지 복사 

$ cp $KERNEL_ROOT/arch/arm64/boot/Image $SDK_ROOT/kernel/Image

2) dtb 이미지 복사 

$cp $KERNEL_ROOT/arch/arm64/boot/dts/nvidia/* $SDK_ROOT/Linux_for_Tegra/kernel/dtb/

3) 모듈 복사

make ARCH=arm64 LOCALVERSION=-tegra CROSS_COMPILE=${CROSS_COMPILE_AARCH64} modules_install \
INSTALL_MOD_PATH=$SDK_ROOT/rootfs

2. 쉘 명령어 추가

.bashrc 파일에 다음 내용 추가하여 컴파일한 이미지 복사

추가 명령어: 

alias cpimg="sudo cp $KERNEL_ROOT/arch/arm64/boot/Image $SDK_ROOT/kernel/Image && \
    sudo cp $KERNEL_ROOT/arch/arm64/boot/dts/nvidia/* $SDK_ROOT/kernel/dtb/"

.bashrc 내용:

export KERNEL_ROOT='/home/nano/ksrc/Linux_for_Tegra/source/public/kernel/kernel-5.10'
export SDK_ROOT='/home/nano/nvidia/nvidia_sdk/JetPack_5.1.4_Linux_JETSON_ORIN_NANO_TARGETS/Linux_for_Tegra'

export CROSS_COMPILE_AARCH64_PATH=/home/nano/l4t-gcc
export CROSS_COMPILE_AARCH64=/home/nano/l4t-gcc/bin/aarch64-buildroot-linux-gnu-

alias cdk="cd ${KERNEL_ROOT}"
alias cds="cd ${SDK_ROOT}"

alias mkclean="make ARCH=arm64 clean"
alias mkproper="make ARCH=arm64 mrproper"

alias mkconfig="make ARCH=arm64 defconfig"
alias mkmanuconfig="make ARCH=arm64 menuconfig"

alias mkimg="make ARCH=arm64 LOCALVERSION=-tegra CROSS_COMPILE=${CROSS_COMPILE_AARCH64} -j8 --output-sync=target V=1 Image"
alias mkdtb="make ARCH=arm64 LOCALVERSION=-tegra CROSS_COMPILE=${CROSS_COMPILE_AARCH64} -j8 --output-sync=target V=1 dtbs"
alias mkmod="make ARCH=arm64 LOCALVERSION=-tegra CROSS_COMPILE=${CROSS_COMPILE_AARCH64} -j8 --output-sync=target V=1 modules"

alias mkmodi="make ARCH=arm64 LOCALVERSION=-tegra CROSS_COMPILE=${CROSS_COMPILE_AARCH64} modules_install INSTALL_MOD_PATH=$SDK_ROOT/rootfs"

alias mkclean="make ARCH=arm64 clean"
alias mkproper="make ARCH=arm64 mrproper"

alias cpimg="sudo cp $KERNEL_ROOT/arch/arm64/boot/Image $SDK_ROOT/kernel/Image && \
    sudo cp $KERNEL_ROOT/arch/arm64/boot/dts/nvidia/* $SDK_ROOT/kernel/dtb/"
