커널 컴파일

1. 컴파일 명령 실행

  1. 명령어를 다음 과정대로 수행한다. 
cdk  

mkclean (옵션)

mkproper (옵션)

mkconfig

mkmanuconfig

mkimg

mkdtb

mkmod

mkdir m_root (옵션)

mkmodo (옵션)

2. 커널 빌드 과정 및 생성 파일 위치

위 명령어를 실행하면 NVIDIA Jetson Orin Nano 환경에서 커널, DTB(Device Tree Blob), 그리고 모듈이 생성됩니다. 각각의 파일이 생성되는 위치는 다음과 같습니다.

1️⃣ 커널 이미지 (Image)

mkimg
- 생성된 파일: Image - 저장 위치:
${KERNER_ROOT}/arch/arm64/boot/Image
- 설명:
커널 이미지 파일로, Jetson 보드에서 실행될 **리눅스 커널의 핵심 실행 파일**입니다. Jetson의 부팅 과정에서 로드됩니다.

2️⃣ 디바이스 트리 바이너리 (DTB)

mkdtb
- 생성된 파일: *.dtb (Device Tree Blob) - 저장 위치:
${KERNER_ROOT}/arch/arm64/boot/dts/nvidia/
- 설명:
DTB 파일은 하드웨어 설정 정보(예: CPU, 메모리, GPIO 등)를 포함하며, Jetson 보드가 부팅될 때 **하드웨어 정보를 커널에 전달하는 역할**을 합니다.

3️⃣ 커널 모듈 (modules)

mkmod
- 생성된 파일: *.ko (Kernel Object) - 저장 위치:
${KERNER_ROOT}/drivers/ (각 모듈별 디렉터리)
- 설명:
커널 모듈(.ko)은 동적으로 로드할 수 있는 커널 기능 확장 파일입니다. 예를 들어, 특정 드라이버를 추가할 때 사용됩니다.

4️⃣ 모듈 설치 (modules_install)

mkdir m_root  
mkmodo
- 설치된 파일 위치:
${KERNER_ROOT}/m_root/lib/modules/$(uname -r)/
- 설명:
빌드된 모듈을 m_root 폴더에 설치합니다. 이후 Jetson 보드에 복사하여 사용할 수 있습니다.

📌 요약

파일 유형 생성 명령어 파일 위치
커널 이미지 (Image) mkimg ${KERNER_ROOT}/arch/arm64/boot/Image
디바이스 트리 바이너리 (DTB) mkdtb ${KERNER_ROOT}/arch/arm64/boot/dts/nvidia/
커널 모듈 (*.ko) mkmod ${KERNER_ROOT}/drivers/ (각 모듈 디렉터리)
모듈 설치 (modules_install) mkmodo ${KERNER_ROOT}/m_root/lib/modules/$(uname -r)/

✅ 이 과정에서 생성된 파일들은 Jetson 보드의 /boot 또는 /lib/modules/로 복사하여 사용할 수 있습니다! 🚀
