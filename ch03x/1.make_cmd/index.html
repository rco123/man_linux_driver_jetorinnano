2. 실행문 간소화

make ARCH=arm64 LOCALVERSION=-tegra CROSS_COMPILE=${CROSS_COMPILE_AARCH64} O=kout -j8 --output-sync=target V=1 Image
make ARCH=arm64 LOCALVERSION=-tegra CROSS_COMPILE=${CROSS_COMPILE_AARCH64} O=kout -j8 --output-sync=target V=1 dtbs
make ARCH=arm64 LOCALVERSION=-tegra CROSS_COMPILE=${CROSS_COMPILE_AARCH64} O=kout -j8 --output-sync=target V=1 modules

1) 모듈 설치

컴파일된 모듈만 다른 디렉토리(m_root) 로 저장하기 위해서 다음 명령어를 수행한다. 

make ARCH=arm64 LOCALVERSION=-tegra CROSS_COMPILE=${CROSS_COMPILE_AARCH64} O=kout modules_install INSTALL_MOD_PATH=$PWD/m_root

3. shell 명령어 작성

아래 내용을 .bashrc 파일에 추가하여 준다.

export KERNEL_ROOT='/home/nano/ksrc/Linux_for_Tegra/source/public/kernel/kernel-5.10'
export SDK_ROOT='/home/nano/nvidia/nvidia_sdk/JetPack_5.1.4_Linux_JETSON_ORIN_NANO_TARGETS/Linux_for_Tegra'

export CROSS_COMPILE_AARCH64_PATH=/home/nano/l4t-gcc
export CROSS_COMPILE_AARCH64=/home/nano/l4t-gcc/bin/aarch64-buildroot-linux-gnu-

alias cdk="cd ${KERNEL_ROOT}"
alias cds="cd ${SDK_ROOT}"

alias mkclean="make ARCH=arm64 clean"
alias mkproper="make ARCH=arm64 mrproper"

alias mkconfig="make ARCH=arm64 defconfig"
alias mkmanuconfig="make ARCH=arm64 menuconfig"

alias mkimg="make ARCH=arm64 LOCALVERSION=-tegra CROSS_COMPILE=${CROSS_COMPILE_AARCH64} -j8 --output-sync=target V=1 Image"
alias mkdtb="make ARCH=arm64 LOCALVERSION=-tegra CROSS_COMPILE=${CROSS_COMPILE_AARCH64} -j8 --output-sync=target V=1 dtbs"
alias mkmod="make ARCH=arm64 LOCALVERSION=-tegra CROSS_COMPILE=${CROSS_COMPILE_AARCH64} -j8 --output-sync=target V=1 modules"

alias mkmodi="make ARCH=arm64 LOCALVERSION=-tegra CROSS_COMPILE=${CROSS_COMPILE_AARCH64} modules_install INSTALL_MOD_PATH=$SDK_ROOT/rootfs"

alias mkclean="make ARCH=arm64 clean"
alias mkproper="make ARCH=arm64 mrproper"

alias cpimg="sudo cp $KERNEL_ROOT/arch/arm64/boot/Image $SDK_ROOT/kernel/Image && \
    sudo cp $KERNEL_ROOT/arch/arm64/boot/dts/nvidia/* $SDK_ROOT/kernel/dtb/"

4. 환경 변수 상세

이 설정 파일은 NVIDIA Jetson Orin Nano 환경에서 커널을 빌드하고 관리하는 다양한 명령어를 alias로 설정한 것입니다.
이를 통해 반복적인 커널 빌드 작업을 더욱 효율적으로 수행할 수 있습니다! 🚀

1️⃣ KERNER_ROOT & SDK_ROOT

export KERNER_ROOT='/home/nano/ksrc/Linux_for_Tegra/source/public/kernel/kernel-5.10'
export SDK_ROOT='/home/nano/nvidia/nvidia_sdk/JetPack_5.1.4_Linux_JETSON_ORIN_NANO_TARGETS/Linux_for_Tegra'
- KERNER_ROOT: 커널 소스 코드가 위치한 경로를 설정합니다. - SDK_ROOT: NVIDIA JetPack SDK가 설치된 경로를 설정합니다.

2️⃣ CROSS_COMPILE_AARCH64_PATH & CROSS_COMPILE_AARCH64

export CROSS_COMPILE_AARCH64_PATH=/home/nano/l4t-gcc
export CROSS_COMPILE_AARCH64=/home/nano/l4t-gcc/bin/aarch64-buildroot-linux-gnu-
- CROSS_COMPILE_AARCH64_PATH: 크로스 컴파일러가 설치된 경로를 설정합니다. - CROSS_COMPILE_AARCH64: aarch64 아키텍처의 크로스 컴파일러 실행 파일을 지정합니다.

경로 이동을 위한 alias 설정

3️⃣ cdk & cds

alias cdk="cd ${KERNER_ROOT}"
alias cds="cd ${SDK_ROOT}"
- cdk: KERNER_ROOT 디렉터리로 빠르게 이동하는 명령어입니다. - cds: SDK_ROOT 디렉터리로 빠르게 이동하는 명령어입니다.

커널 빌드를 위한 alias 설정

4️⃣ mkclean

alias mkclean="make ARCH=arm64 clean"
- 커널 빌드 디렉토리를 정리하여 불필요한 파일을 제거합니다.

5️⃣ mkproper

alias mkproper="make ARCH=arm64 mrproper"
- mkclean보다 더 철저하게 정리하며, .config 파일과 빌드 아티팩트도 제거합니다.

6️⃣ mkconfig

alias mkconfig="make ARCH=arm64 defconfig"
- 기본적인 커널 설정 파일(defconfig)을 생성합니다.

7️⃣ mkmanuconfig

alias mkmanuconfig="make ARCH=arm64 menuconfig"
- 커널 설정을 GUI 방식으로 변경할 수 있도록 메뉴 기반의 설정 창을 엽니다.

커널 이미지 및 모듈 빌드 alias

8️⃣ mkimg

alias mkimg="make ARCH=arm64 LOCALVERSION=-tegra CROSS_COMPILE=${CROSS_COMPILE_AARCH64} -j8 --output-sync=target V=1 Image"
- Tegra용 커널 이미지(Image)를 빌드하는 명령어입니다. - -j8: 8개의 코어를 사용하여 빌드 속도를 향상합니다.

9️⃣ mkdtb

alias mkdtb="make ARCH=arm64 LOCALVERSION=-tegra CROSS_COMPILE=${CROSS_COMPILE_AARCH64} -j8 --output-sync=target V=1 dtbs"
- 디바이스 트리 바이너리(DTB, Device Tree Blob) 파일을 생성하는 명령어입니다.

🔟 mkmod

alias mkmod="make ARCH=arm64 LOCALVERSION=-tegra CROSS_COMPILE=${CROSS_COMPILE_AARCH64} -j8 --output-sync=target V=1 modules"
- 커널 모듈을 빌드하는 명령어입니다.

1️⃣1️⃣ mkmodo

alias mkmodo="make ARCH=arm64 LOCALVERSION=-tegra CROSS_COMPILE=${CROSS_COMPILE_AARCH64} modules_install INSTALL_MOD_PATH=$PWD/m_root"
- 빌드된 커널 모듈을 m_root 디렉터리에 설치하는 명령어입니다.

✅ 요약 이 설정 파일은 NVIDIA Jetson Orin Nano 환경에서 커널을 빌드하고 관리하는 다양한 명령어를 alias로 설정한 것입니다.
이를 통해 반복적인 커널 빌드 작업을 더욱 효율적으로 수행할 수 있습니다! 🚀
