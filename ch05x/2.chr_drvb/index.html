문자 드라이브 II

메이저 번호는 **커널에서 자동 할당**할 수도 있지만, 특정 메이저 번호를 직접 **고정 지정**할 수도 있습니다.
이는 **특정 장치와의 호환성 유지**나 **사용자 정의 장치 파일을 일정하게 유지**하기 위해 필요할 수 있습니다.

1. 메이저 번호 고정 지정하는 방법

기본적으로 메이저 번호를 자동 할당하는 코드: 

alloc_chrdev_region(&dev_num, 0, 1, DEVICE_NAME);
위 코드는 커널이 자동으로 메이저 번호를 할당하지만, **고정 번호**를 지정하려면 register_chrdev_region()을 사용합니다.

1) register_chrdev_region() 사용 고정된 메이저 번호를 지정하는 코드: 

#define MY_MAJOR 240  // 사용할 고정 메이저 번호

static dev_t dev_num = MKDEV(MY_MAJOR, 0); // 메이저 240, 마이너 0

if (register_chrdev_region(dev_num, 1, DEVICE_NAME) < 0) {
    printk(KERN_ALERT "Failed to register device with fixed major number\n");
    return -1;
}

  • #define MY_MAJOR 240 → 240을 메이저 번호로 지정
  • MKDEV(MY_MAJOR, 0) → dev_t 타입 변수 생성 (메이저 240, 마이너 0)
  • register_chrdev_region(dev_num, 1, DEVICE_NAME) → 지정한 메이저 번호를 사용하여 등록

2. 메이저 번호 고정 vs 자동 할당 비교

방법 함수 장점 단점
자동 할당 alloc_chrdev_region() 충돌 위험 없음, 다른 드라이버와 안전하게 사용 가능 부팅할 때마다 번호가 바뀔 수 있음
고정 할당 register_chrdev_region() 항상 같은 번호 사용 가능, /dev 파일 유지 용이 다른 드라이버와 충돌할 가능성 있음

3. 메이저 번호 고정된 캐릭터 드라이버 코드

아래 코드는 메이저 번호 240을 고정으로 지정하는 캐릭터 드라이버입니다.

1) char_driver_fixed.c 

#include <linux/module.h>
#include <linux/fs.h>
#include <linux/cdev.h>
#include <linux/uaccess.h>

#define DEVICE_NAME "mychar_fixed"
#define MY_MAJOR 240  // 고정 메이저 번호
#define BUF_SIZE 1024

static dev_t dev_num = MKDEV(MY_MAJOR, 0); // 메이저 240, 마이너 0
static struct cdev my_cdev;
static char device_buffer[BUF_SIZE];

static int my_open(struct inode *inode, struct file *file) {
    printk(KERN_INFO "mychar_fixed: Device opened\n");
    return 0;
}

static int my_release(struct inode *inode, struct file *file) {
    printk(KERN_INFO "mychar_fixed: Device closed\n");
    return 0;
}

static ssize_t my_read(struct file *file, char __user *user_buffer, size_t size, loff_t *offset) {
    int bytes_read = size < BUF_SIZE ? size : BUF_SIZE;
    if (copy_to_user(user_buffer, device_buffer, bytes_read)) {
        return -EFAULT;
    }
    printk(KERN_INFO "mychar_fixed: Read %d bytes\n", bytes_read);
    return bytes_read;
}

static ssize_t my_write(struct file *file, const char __user *user_buffer, size_t size, loff_t *offset) {
    int bytes_write = size < BUF_SIZE ? size : BUF_SIZE;
    if (copy_from_user(device_buffer, user_buffer, bytes_write)) {
        return -EFAULT;
    }
    printk(KERN_INFO "mychar_fixed: Written %d bytes\n", bytes_write);
    return bytes_write;
}

static struct file_operations fops = {
    .owner = THIS_MODULE,
    .open = my_open,
    .release = my_release,
    .read = my_read,
    .write = my_write,
};

static int __init mychar_fixed_init(void) {
    if (register_chrdev_region(dev_num, 1, DEVICE_NAME) < 0) {
        printk(KERN_ALERT "Failed to register device with fixed major number\n");
        return -1;
    }
    cdev_init(&my_cdev, &fops);
    if (cdev_add(&my_cdev, dev_num, 1) < 0) {
        unregister_chrdev_region(dev_num, 1);
        printk(KERN_ALERT "Failed to add cdev\n");
        return -1;
    }
    printk(KERN_INFO "mychar_fixed: Registered with Major %d, Minor %d\n", MAJOR(dev_num), MINOR(dev_num));
    return 0;
}

static void __exit mychar_fixed_exit(void) {
    cdev_del(&my_cdev);
    unregister_chrdev_region(dev_num, 1);
    printk(KERN_INFO "mychar_fixed: Unregistered device\n");
}

module_init(mychar_fixed_init);
module_exit(mychar_fixed_exit);

MODULE_LICENSE("GPL");
MODULE_AUTHOR("Jetson Orin Nano Dev");
MODULE_DESCRIPTION("Character Device Driver with Fixed Major Number");

4. 드라이버 빌드 및 테스트

1) Makefile 작성 

obj-m += char_driver.o
obj-m += char_driver_fixed.o

all:
        make -C /lib/modules/$(shell uname -r)/build M=$(PWD) modules

clean:
        make -C /lib/modules/$(shell uname -r)/build M=$(PWD) clean

2) 커널 모듈 빌드 

make

3) 모듈 삽입 

sudo insmod char_driver_fixed.ko

4) 메이저 번호 확인 

dmesg | grep "mychar_fixed"
출력 예: 
[  123.456789] mychar_fixed: Registered with Major 240, Minor 0

5) /dev에 디바이스 파일 생성 

sudo mknod /dev/mychar_fixed c 240 0
sudo chmod 666 /dev/mychar_fixed

6) 상위 프로그램 실행 

gcc test_app_fixed.c -o test_app_fixed
./test_app_fixed

(1) test_app_fixed.c - 상위 사용자 애플리케이션
#include <stdio.h>
#include <stdlib.h>
#include <fcntl.h>
#include <unistd.h>
#include <string.h>

#define DEVICE "/dev/mychar_fixed"

int main() {
    int fd;
    char write_buf[] = "Hello Jetson Orin Nano!";
    char read_buf[1024];

    fd = open(DEVICE, O_RDWR);
    if (fd < 0) {
        perror("Failed to open device");
        return -1;
    }

    write(fd, write_buf, strlen(write_buf));
    printf("Written to device: %s\n", write_buf);

    read(fd, read_buf, sizeof(read_buf));
    printf("Read from device: %s\n", read_buf);

    close(fd);
    return 0;
}

(6) 모듈 제거

sudo rmmod char_driver_fixed

5. 결론

Jetson Orin Nano에서 **고정된 메이저 번호를 사용하는 캐릭터 드라이버**를 구현하는 방법을 배웠습니다.

  • register_chrdev_region()을 사용하여 **240번 메이저 번호**를 고정
  • /dev/mychar_fixed 파일을 수동으로 생성 (mknod)
  • 항상 동일한 메이저 번호로 장치를 인식할 수 있음

이제 필요한 메이저 번호를 사용하여, Jetson Orin Nano에서 원하는 장치 드라이버를 더욱 안정적으로 사용할 수 있습니다. 🚀
