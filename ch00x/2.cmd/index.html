cmd

리눅스에서 자주 사용되는 명령어는 다음과 같습니다.

1. 파일 및 디렉터리 관련 명령어

ls - 파일 및 디렉터리 목록 출력

ls -l        # 상세 목록 보기
ls -a        # 숨김 파일 포함 목록 보기
ls -lh       # 파일 크기를 사람이 읽기 쉬운 형태로 표시

cd - 디렉터리 이동

cd /home/user       # 특정 디렉터리로 이동
cd ..               # 한 단계 상위 디렉터리로 이동
cd ~/Documents      # 홈 디렉터리 기준으로 이동

pwd - 현재 작업 디렉터리 확인

pwd

mkdir - 디렉터리 생성

mkdir my_folder     # my_folder 디렉터리 생성
mkdir -p dir1/dir2  # 부모 디렉터리까지 포함하여 생성

rm - 파일 및 디렉터리 삭제

rm file.txt         # 파일 삭제
rm -r my_folder     # 디렉터리 삭제 (하위 파일 포함)
rm -f file.txt      # 강제 삭제

cp - 파일 및 디렉터리 복사

cp file1.txt file2.txt  # 파일 복사
cp -r dir1 dir2         # 디렉터리 복사

mv - 파일 및 디렉터리 이동 또는 이름 변경

mv oldname.txt newname.txt   # 파일 이름 변경
mv file.txt /home/user       # 파일 이동

find - 특정 파일 검색

find /home -name "*.txt"  # /home 디렉터리에서 .txt 파일 검색
find . -type f -size +10M # 10MB 이상의 파일 검색

2. 파일 내용 조회 및 조작

cat - 파일 내용 출력

cat file.txt

less - 파일 내용을 한 화면씩 출력

less file.txt

grep - 특정 문자열 검색

grep "hello" file.txt        # 'hello'가 포함된 라인 찾기
grep -i "hello" file.txt     # 대소문자 구분 없이 검색
grep -r "main()" /home/user  # 디렉터리 내에서 재귀적으로 검색

head / tail - 파일의 앞 또는 뒤에서 일부 출력

head -n 10 file.txt  # 파일의 처음 10줄 출력
tail -n 10 file.txt  # 파일의 마지막 10줄 출력
tail -f log.txt      # 로그 파일 실시간 출력

wc - 파일의 단어, 줄, 바이트 수 계산

wc -l file.txt  # 파일의 줄 수 출력
wc -w file.txt  # 파일의 단어 수 출력

3. 프로세스 및 시스템 관리

ps - 실행 중인 프로세스 목록 출력

ps aux      # 모든 프로세스 표시
ps -ef      # 상세 정보 포함

top - 실시간 프로세스 모니터링

top

htop - 향상된 실시간 프로세스 모니터링 (설치 필요)

htop

kill - 특정 프로세스를 종료

kill 1234    # 프로세스 ID 1234 종료
kill -9 1234 # 강제 종료

pkill - 특정 이름을 가진 프로세스 종료

pkill firefox

df - 디스크 사용량 확인

df -h  # 사람이 읽기 쉬운 형태로 디스크 사용량 출력

du - 특정 디렉터리 크기 확인

du -sh /home/user  # /home/user 디렉터리 크기 출력

free - 메모리 사용량 확인

free -h

4. 사용자 및 권한 관리

whoami - 현재 로그인한 사용자 확인

whoami

who - 현재 로그인한 사용자 목록 확인

who

chmod - 파일 및 디렉터리 권한 변경

chmod 755 script.sh  # 소유자는 읽기, 쓰기, 실행 / 그룹 및 기타 사용자는 읽기, 실행 권한 부여
chmod +x script.sh   # 실행 권한 추가

chown - 파일 소유자 변경

chown user:user file.txt  # 파일 소유자를 user로 변경

5. 네트워크 관련 명령어

ping - 네트워크 연결 테스트

ping google.com

curl - URL에서 데이터 가져오기

curl -O http://example.com/file.zip  # 파일 다운로드

wget - 파일 다운로드

wget http://example.com/file.zip

netstat - 네트워크 연결 확인

netstat -tulnp  # 현재 사용 중인 포트 및 프로세스 확인

ifconfig / ip - 네트워크 설정 확인

ifconfig eth0
ip addr show

6. 패키지 관리

Ubuntu / Debian (APT)

sudo apt update        # 패키지 목록 업데이트
sudo apt upgrade       # 모든 패키지 업데이트
sudo apt install vim   # vim 설치
sudo apt remove vim    # vim 제거

CentOS / RHEL (YUM)

sudo yum update
sudo yum install vim

7. 압축 및 아카이브 관리

tar - 파일 아카이브 및 압축

tar -cvf archive.tar directory/   # 디렉터리를 tar 파일로 묶기
tar -xvf archive.tar              # tar 파일 풀기
tar -czvf archive.tar.gz directory/  # gzip 압축
tar -xzvf archive.tar.gz             # 압축 해제

zip / unzip - ZIP 파일 압축 및 해제

zip -r archive.zip directory/  # ZIP 파일로 압축
unzip archive.zip              # ZIP 파일 해제

이 외에도 리눅스에서는 많은 명령어가 사용됩니다. 위의 명령어들은 기본적으로 자주 사용되며, 필요에 따라 추가적인 옵션을 조합하여 활용할 수 있습니다. 🚀
