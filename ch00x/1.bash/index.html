BASH

Bash(Bourne Again Shell) 은 리눅스 및 유닉스 계열 시스템에서 가장 널리 사용되는 쉘(Shell)입니다.

  • GNU 프로젝트에서 개발되었으며, Bourne Shell(sh)을 확장한 버전입니다.
  • 터미널에서 명령어를 실행하거나, .sh 파일로 스크립트를 작성하여 자동화할 수 있습니다.
  • 변수, 조건문, 반복문, 함수 등 프로그래밍 요소를 포함하여 다양한 기능을 제공합니다.

2. 변수 설정(Variable Setting)

Bash에서 변수를 설정할 때는 변수명=값 형식으로 사용합니다.
변수명과 = 사이에 공백이 있으면 안 됩니다.

#!/usr/bin/env bash

NAME="Alice"
AGE=25

echo "이름: $NAME"
echo "나이: ${AGE}"

3. 큰따옴표("")와 작은따옴표('')의 차이

Bash에서는 문자열을 감쌀 때 큰따옴표("")와 작은따옴표('')의 동작 방식이 다릅니다.

1) 큰따옴표("") - 큰따옴표 안에서는 **변수와 명령어 치환($)이 가능**합니다.

#!/usr/bin/env bash

NAME="Alice"
echo "Hello, $NAME"   # Hello, Alice

2) 작은따옴표('') - 작은따옴표 안에서는 변수나 명령어 치환이 이루어지지 않습니다.

#!/usr/bin/env bash

NAME="Alice"
echo 'Hello, $NAME'   # Hello, $NAME (변수 치환 안 됨)

3) 결론 - 변수 값을 포함하는 문자열을 사용할 경우: 큰따옴표("")를 사용합니다. - 문자 그대로 출력해야 할 경우: 작은따옴표('')를 사용합니다.

4. 변수의 변환(Variable Transformation)

Bash에서는 변수 값을 다양한 형태로 변환할 수 있습니다.

#!/usr/bin/env bash

TEXT="Hello World"

echo "${TEXT,,}"    # hello world (소문자로 변환)
echo "${TEXT^^}"    # HELLO WORLD (대문자로 변환)
echo "${TEXT:0:5}"  # Hello (부분 문자열 추출)

echo {apple,banana,kiwi}  # apple banana kiwi
touch file_{1..3}.txt     # file_1.txt file_2.txt file_3.txt 생성

5. 변수 중괄호 기능(Brace Expansion)

Brace Expansion은 {} 안에 여러 값을 넣어 확장하는 기능을 제공합니다.

#!/usr/bin/env bash

echo {apple,banana,kiwi}  # apple banana kiwi
touch file_{1..3}.txt     # file_1.txt file_2.txt file_3.txt 생성

6. () 실행 기능(서브쉘, 명령 그룹핑)

Bash에서 ()는 **서브쉘 실행**과 **명령 그룹핑**에 사용됩니다.

1) 서브쉘 실행 () 안에서 실행되는 명령어는 별도의 서브쉘에서 실행되므로, 현재 쉘 환경에 영향을 주지 않습니다.

#!/usr/bin/env bash

VAR="original"
(
  VAR="changed in subshell"
  echo "서브쉘 내부: $VAR"
)
echo "서브쉘 외부: $VAR"  # 원래 값 유지됨

2) 명령 그룹핑 여러 명령을 하나의 실행 블록으로 묶습니다.

(echo "첫 번째 명령"; echo "두 번째 명령")

7. 변수 수학 연산(Arithmetic Expansion)

Bash에서는 $(( ... )) 구문을 사용하여 산술 연산을 수행합니다.

#!/usr/bin/env bash

NUM1=10
NUM2=3

SUM=$((NUM1 + NUM2))
echo "SUM: $SUM"

SUB=$((NUM1 - NUM2))
echo "SUB: $SUB"

MUL=$((NUM1 * NUM2))
echo "MUL: $MUL"

DIV=$((NUM1 / NUM2))
echo "DIV: $DIV"  # 정수 나눗셈

8. 연산자(Conditionals and Comparisons)

Bash에서 조건문을 사용하려면 **비교 연산자**와 **논리 연산자**를 이해해야 합니다.

1) 변수 조건문, 비교문

Bash에서 조건문 안에서 변수를 비교할 때는 test 명령어 또는 대괄호([])를 사용합니다.

#!/usr/bin/env bash

NUMBER=10

if [ "$NUMBER" -gt 5 ]; then
  echo "NUMBER는 5보다 큽니다."
fi

2) 비교 연산자(Comparison Operators)

숫자 비교 (-eq, -ne, -gt, -lt, -ge, -le)

연산자 의미
-eq 두 값이 같으면 참
-ne 두 값이 다르면 참
-gt 왼쪽 값이 크면 참
-lt 왼쪽 값이 작으면 참
-ge 왼쪽 값이 크거나 같으면 참
-le 왼쪽 값이 작거나 같으면 참 
#!/usr/bin/env bash

NUM1=10
NUM2=5

if [ "$NUM1" -gt "$NUM2" ]; then
  echo "NUM1이 NUM2보다 큽니다."
fi

문자열 비교 (=, !=, -z, -n)

연산자 의미
= 문자열이 같으면 참
!= 문자열이 다르면 참
-z 문자열이 비어 있으면 참
-n 문자열이 비어 있지 않으면 참 
#!/usr/bin/env bash

TEXT="Hello"

if [ "$TEXT" = "Hello" ]; then
  echo "같은 문자열입니다."
fi

3) 조건 연산자(Logical Operators)

연산자 의미
&& AND 연산 (둘 다 참일 때 참)
|| OR 연산 (하나라도 참이면 참)
! NOT 연산 (참 → 거짓, 거짓 → 참) 
#!/usr/bin/env bash

NUM=15

if [ "$NUM" -gt 10 ] && [ "$NUM" -lt 20 ]; then
  echo "NUM은 10보다 크고 20보다 작습니다."
fi

4) 파일 연산자(File Test Operators)

연산자 의미
-e 파일이 존재하면 참
-f 파일이 일반 파일이면 참
-d 디렉터리이면 참
-s 파일 크기가 0보다 크면 참 
#!/usr/bin/env bash

if [ -e "test.txt" ]; then
  echo "파일이 존재합니다."
fi

9. 제어문(Control Structures)

1) if 문

if [ "$NUM" -gt 5 ]; then
  echo "5보다 큼"
fi

2) case 문

case "$INPUT" in
  "start") echo "시작합니다." ;;
  "stop") echo "중지합니다." ;;
  "restart") echo "다시 시작합니다." ;;
  *) echo "알 수 없는 명령입니다." ;;
esac

3) for 문

for i in {1..5}
do
  echo "숫자: $i"
done
  • for i in $(seq 1 5)
  • for i in $(seq 1 2 10) # 1부터 10까지 2씩 증가
  • for i in *.txt
  • for i in $(cat file.txt)
  • for i in $(ls)
  • for i in "${array[@]}" # array=("하나" "둘" "셋")

4) while 문

count=1
while [ $count -le 5 ]
do
  echo "Count: $count"
  ((count++))
done

10. 함수(Function)

Bash에서는 함수를 정의하고 호출할 수 있습니다.

#!/usr/bin/env bash

# 함수 정의
greet() {
  echo "안녕하세요, $1님!"
}

# 함수 호출
greet "Alice"
greet "Bob"

1) 반환값 처리

sum() {
  local result=$(( $1 + $2 ))
  echo $result
}

RESULT=$(sum 3 5)
echo "3 + 5 = $RESULT"

11. 종합 예시

#!/usr/bin/env bash

echo "첫 번째 숫자를 입력하세요:"
read NUM1
echo "두 번째 숫자를 입력하세요:"
read NUM2

sum() {
  local result=$(( $1 + $2 ))
  echo $result
}

SUM=$(sum $NUM1 $NUM2)

if [ "$SUM" -gt 10 ]; then
  echo "두 수의 합($SUM)은 10보다 큽니다."
else
  echo "두 수의 합($SUM)은 10 이하입니다."
fi

echo "1부터 $SUM 까지 숫자를 출력합니다."
for ((i=1; i<=SUM; i++))
do
  echo "$i"
done

echo "프로그램 종료"
