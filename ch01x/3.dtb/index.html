**DTB(Device Tree Blob)

1. DTB(Device Tree Blob) 개요

DTB(Device Tree Blob)**는 **Device Tree Source(DTS) 파일을 바이너리 형태로 변환한 파일입니다.
리눅스 커널은 DTB 파일을 로드하여 하드웨어 구성을 이해하고 적절한 드라이버를 로드합니다.

DTB의 주요 기능

  1. 하드웨어 정보를 커널에 제공
  2. CPU, 메모리, GPIO, SPI, I2C 등의 장치를 정의.

  3. 커널이 이를 읽고 해당 드라이버를 로드.

  4. 커널과 하드웨어의 분리

  5. 커널 코드와 하드웨어 구성을 분리하여 유지보수성을 높임.

  6. 같은 커널을 사용하면서도 하드웨어 구성 변경이 가능.

  7. 빠른 처리 가능

  8. 바이너리 형식이므로 커널이 효율적으로 파싱하여 적용할 수 있음.

2. DTB 변환 과정 예제

DTB는 사람이 읽기 어려운 바이너리 파일이므로, **DTS(Device Tree Source)**라는 사람이 읽기 쉬운 형식으로 먼저 정의한 후 DTB로 변환합니다.

예제: DTS 파일

다음은 my_led.dts라는 이름의 Device Tree Source(DTS) 파일입니다.
이 파일은 GPIO 21번 핀에 연결된 LED를 정의합니다.

/dts-v1/;

/ {
    my_led {
        compatible = "my_led_run";  /* 호환되는 장치 유형 */
        label = "my_led";           /* LED 이름 */
        pin = <21>;                 /* GPIO 핀 번호 */
        active_state = <0>;         /* 활성화 상태 */
        default_state = "off";      /* 기본 상태 */
    };
};

3. DTS → DTB 변환 (컴파일)

DTS 파일을 Device Tree Blob(DTB) 파일로 변환하려면 dtc(Device Tree Compiler)를 사용합니다.

명령어

dtc -I dts -O dtb -o my_led.dtb my_led.dts

명령어 설명

  • dtc : Device Tree Compiler, DTS를 DTB로 변환하는 도구.
  • -I dts : 입력 파일 형식을 DTS로 지정.
  • -O dtb : 출력 파일 형식을 DTB로 지정 (바이너리 변환).
  • -o my_led.dtb : 변환된 파일명을 my_led.dtb로 저장.

4. DTB → DTS 변환 (역컴파일)

DTB 파일을 사람이 읽을 수 있는 DTS 파일로 변환하려면 **역컴파일**을 수행합니다.

명령어

dtc -I dtb -O dts -o my_led.dts my_led.dtb

명령어 설명

  • -I dtb : 입력 파일이 DTB 형식임을 지정.
  • -O dts : 출력 파일을 DTS 형식으로 변환.
  • -o my_led.dts : 변환된 DTS 파일명을 my_led.dts로 저장.

5. 변환된 DTS 예제

위의 명령어를 실행하면 my_led.dts 파일이 다음과 같은 형태로 생성됩니다.

/dts-v1/;

/ {

        my_led {
                compatible = "my_led_run";
                label = "my_led";
                pin = <0x15>;
                active_state = <0x00>;
                default_state = "off";
        };
};

6. 최종 정리

1. DTS(Device Tree Source) 작성

  • 사람이 읽기 쉬운 하드웨어 정의 파일.

2. DTB → DTS 변환 (역컴파일)

dtc -I dtb -O dts -o my_led.dts my_led.dtbo
  • DTB를 다시 DTS로 변환하여 내용을 확인하고 수정 가능.

3. DTS → DTB 변환 (컴파일)

dtc -I dts -O dtb -o my_led.dtb my_led.dts
  • DTB(Device Tree Blob)로 변환하여 커널이 사용할 수 있도록 함.
