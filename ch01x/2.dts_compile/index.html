DTS 컴파일

DTS(Device Tree Source) 파일은 리눅스 커널에서 직접 사용되지 않으며, **DTB(Device Tree Blob)**로 컴파일되어 사용됩니다. DTS를 DTB로 컴파일하는 과정과 관련 명령어에 대해 설명드리겠습니다.

1. DTS 컴파일 과정

DTS 파일은 텍스트 기반의 소스 파일이며, 이를 바이너리 형식인 DTB로 변환해야 리눅스 커널에서 사용할 수 있습니다. 이 변환 과정은 **dtc(Device Tree Compiler)**라는 도구를 사용하여 수행됩니다.

1) DTS → DTB

  • DTS 파일을 DTB로 컴파일합니다.
  • DTB는 바이너리 형식으로, 리눅스 커널이 하드웨어 정보를 파싱하는 데 사용됩니다.

2) 컴파일 도구

  • dtc는 리눅스 커널 소스 트리에 포함된 도구입니다.
  • 커널 소스 트리의 scripts/dtc/ 디렉토리에서 찾을 수 있습니다.

2. DTS 컴파일 명령어

DTS 파일을 DTB로 컴파일하는 기본 명령어는 다음과 같습니다.

dtc -I dts -O dtb -o output.dtb input.dts

옵션 설명:

  • -I dts: 입력 파일 형식을 DTS로 지정합니다.
  • -O dtb: 출력 파일 형식을 DTB로 지정합니다.
  • -o output.dtb: 출력 파일 이름을 지정합니다.
  • input.dts: 입력 DTS 파일 이름을 지정합니다.

3. 예제: DTS 컴파일

1) 예제 DTS 파일

다음은 간단한 DTS 파일 예제입니다. 파일 이름은 my_board.dts로 가정합니다.

/dts-v1/;

/ {
    compatible = "vendor,board-name";
    model = "My Board";

    cpus {
        cpu@0 {
            compatible = "arm,cortex-a53";
            device_type = "cpu";
            reg = <0x0>;
        };
    };

    memory@80000000 {
        device_type = "memory";
        reg = <0x80000000 0x40000000>;
    };

    uart0: serial@1000 {
        compatible = "ns16550a";
        reg = <0x1000 0x100>;
        interrupts = <0x0 0x1>;
    };
};

2) 컴파일 명령어 실행

위의 my_board.dts 파일을 DTB로 컴파일하려면 다음 명령어를 실행합니다.

dtc -I dts -O dtb -o my_board.dtb my_board.dts

3) 결과

  • my_board.dtb 파일이 생성됩니다.
  • 이 파일은 바이너리 형식이며, 리눅스 커널에서 하드웨어 정보를 파싱하는 데 사용됩니다.

4. 컴파일된 DTB 파일 확인

컴파일된 DTB 파일은 바이너리 형식이므로, 텍스트로 내용을 확인하려면 fdtdump 도구를 사용할 수 있습니다.

명령어

fdtdump my_board.dtb

출력 예시

/dts-v1/;
// magic:       0xd00dfeed
// totalsize:       0x1e4 (484)
// off_dt_struct:   0x38
// off_dt_strings:  0x1a8
// off_mem_rsvmap:  0x28
// version:     17
// last_comp_version:   16
// boot_cpuid_phys: 0x0
// size_dt_strings: 0x3c
// size_dt_struct:  0x170

/ {
    compatible = "vendor,board-name";
    model = "My Board";
    ...
};

5. 커널 소스 트리에서의 컴파일

리눅스 커널 소스 트리에서는 make 명령어를 사용하여 DTS 파일을 DTB로 컴파일할 수 있습니다.

1) 커널 소스 트리 구조

  • DTS 파일은 일반적으로 arch/<아키텍처>/boot/dts/ 디렉토리에 위치합니다.
  • 예: ARM 아키텍처의 경우 arch/arm64/boot/dts/

2) 커널 빌드 시스템을 통한 컴파일

  • 특정 DTS 파일을 DTB로 컴파일하려면 다음 명령어를 사용합니다: 
    make ARCH=<아키텍처> <DTS 파일 이름>.dtb
  • 예: ARM 아키텍처에서 my_board.dts를 컴파일하는 경우: 
    make ARCH=arm my_board.dtb

3) 모든 DTS 파일 컴파일

  • 모든 DTS 파일을 한 번에 컴파일하려면 다음 명령어를 사용합니다: 
    make ARCH=<아키텍처> dtbs
  • 예: ARM 아키텍처의 경우: 
    make ARCH=arm dtbs

6. DTS 컴파일 과정 요약

  1. DTS 파일 작성: 하드웨어 정보를 DTS 형식으로 작성합니다.
  2. 컴파일: dtc 도구를 사용하여 DTS를 DTB로 컴파일합니다.
  3. DTB 사용: 컴파일된 DTB 파일을 부트로더가 커널에 전달합니다.
  4. 커널 파싱: 커널이 DTB를 파싱하여 하드웨어를 초기화합니다.

7. 결론

DTS 파일은 dtc 도구를 사용하여 DTB로 컴파일되며, 이 과정은 리눅스 커널이 하드웨어를 인식하고 초기화하는 데 필수적입니다. 예제와 함께 제공된 명령어를 사용하면 DTS 파일을 쉽게 컴파일할 수 있습니다. 컴파일된 DTB 파일은 부트로더가 커널에 전달하여 하드웨어 정보로 사용됩니다.
