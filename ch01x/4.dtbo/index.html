**DTB(Device Tree Blob)

DTBO(Device Tree Blob Overlay)란?

1. 개요

Device Tree Blob Overlay(DTBO)는 기존의 Device Tree Blob(DTB)에 추가적으로 설정을 덧붙이거나 수정할 때 사용하는 기법입니다. DTBO는 하드웨어의 변경 사항을 반영할 수 있도록 유연한 구성을 제공합니다. DTBO는 주로 Linux 커널에서 사용되며, 특정 하드웨어 보드의 설정을 변경하거나 추가할 때 활용됩니다.

2. DTBO 생성 과정

DTBO는 DTS(Device Tree Source) 파일을 작성한 후, 이를 컴파일하여 DTBO(Device Tree Blob Overlay) 파일로 변환하는 과정으로 생성됩니다.

2.1 DTS 파일 작성

아래는 예제 DTS 파일로, 특정 GPIO 핀(21번 핀)에 LED를 설정하는 예제입니다.

/dts-v1/;

/ {
    my_led {
        compatible = "my_led_run";  /* 호환되는 장치 유형 */
        label = "my_led";           /* LED 이름 */
        pin = <21>;                 /* GPIO 핀 번호 */
        active_state = <0>;         /* 활성화 상태 */
        default_state = "off";      /* 기본 상태 */
    };
};

2.2 DTS를 DTBO로 변환

DTS 파일을 DTBO로 변환하려면 dtc(Device Tree Compiler)를 사용합니다. 다음 명령어를 실행하면 my_led.dtbo 파일이 생성됩니다.

dtc -O dtb -o my_led.dtbo -b 0 -@ my_led.dts

명령어 설명:

  • -O dtb : 출력 형식을 DTB(바이너리)로 지정
  • -o my_led.dtbo : 출력 파일 이름을 지정
  • -b 0 : 기본 주소 오프셋을 0으로 설정
  • -@ : 오버레이 지원을 활성화

이제 my_led.dtbo가 생성되었으며, 이를 기존의 DTB 파일에 적용할 수 있습니다.

3. DTBO를 다시 DTS로 변환하는 과정

DTBO 파일을 다시 DTS로 변환하려면 dtc 명령어를 사용하여 디컴파일합니다.

dtc -I dtb -O dts -o my_led_decompiled.dts my_led.dtbo

명령어 설명:

  • -I dtb : 입력 파일을 DTB(바이너리)로 지정
  • -O dts : 출력 파일을 DTS(소스)로 지정
  • -o my_led_decompiled.dts : 변환된 DTS 파일의 이름

이제 my_led_decompiled.dts 파일을 열어 원래의 DTS 내용을 확인할 수 있습니다. 변환 과정에서 주석이나 일부 포맷이 변경될 수 있지만, 기본적인 구조와 설정 값은 유지됩니다.

1) 역변환된 DTS 예제

아래는 dtc를 이용해 DTBO를 DTS로 변환한 후의 예제입니다:

/dts-v1/;

/ {
    fragment@0 {
        target-path = "/";
        __overlay__ {
            my_led {
                compatible = "my_led_run";
                label = "my_led";
                pin = <21>;
                active_state = <0>;
                default_state = "off";
            };
        };
    };
};

변환된 DTS는 원래의 DTS와 유사하지만, fragment@0 및 __overlay__ 노드가 포함되어 오버레이 구조를 명확하게 나타냅니다.

4. 결론

DTBO는 기존의 DTB 파일을 수정하지 않고도 하드웨어 설정을 변경할 수 있는 유용한 방법입니다. DTS 파일을 작성하여 DTBO로 변환하고, 필요하면 다시 DTS로 변환하는 과정을 이해하면, 다양한 하드웨어 설정을 보다 유연하게 관리할 수 있습니다.
